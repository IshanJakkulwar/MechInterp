**Abstract**



Most modern AI systems generate fluent language but sometimes produce false statements. These statement are sometimes genuine mistakes, but sometimes lies are crafted against the original programming protocols to either 'trick' the user or support them. Most current approaches to detection rely on training an outside classifier on outputs to detect lies. Therefore, this study questioned whether 'neural networks represent truth and falsehood between its layers' and whether we could use methods to effectively produce a latent truthfulness detection system for AI models.
